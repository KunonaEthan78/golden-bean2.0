## About Laravel

Laravel is a web application framework with expressive, elegant syntax. It eases common tasks in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing)
- [Powerful dependency injection container](https://laravel.com/docs/container)
- [Session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) support
- [Database ORM](https://laravel.com/docs/eloquent)
- [Schema migrations](https://laravel.com/docs/migrations)
- [Job queues](https://laravel.com/docs/queues)
- [Event broadcasting](https://laravel.com/docs/broadcasting)
